사용 방법

  1. 업데이트 전 CEFR가 정상 표시되던 최신 index.html (v6.4.98 이상)을 선택합니다. 이미 설치한 구버전은 선택하지 마세요.
  2. 수정된 HTML 만들기를 누르면 새 파일이 저장됩니다.
  3. 수정 파일을 확인한 뒤, GitHub Pages의 index.html로 교체합니다. 기존 파일은 백업하세요.
HTML 파일을 선택해 주세요. 앱의 공식 학습 데이터베이스는 변경하지 않습니다.
